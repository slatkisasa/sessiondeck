# Security policy

## Supported versions

Security fixes target the latest published release. Update to that release before
reporting a problem, when possible.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/slatkisasa/sessiondeck/security/advisories/new)
for suspected vulnerabilities. Do not disclose security details in a public issue
or pull request before the maintainer has investigated them.

Describe the affected version, expected and observed behavior, and minimal steps
to reproduce with synthetic data. Never attach passwords, authentication tokens,
cookies, real account identifiers, Battle.net configuration or backups, or complete
account caches. Redact personal information from logs and screenshots.

SessionDeck selects sessions already retained by the Battle.net launcher. Reports
about accidental collection of credentials, exposure of account metadata, unsafe
configuration writes, or untrusted release downloads are especially relevant.

No response-time commitment is offered for this personal project. After a report
is confirmed, coordinate disclosure and a fix with the maintainer through the
private advisory.
